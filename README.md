# ScalpBot

Автономний Android-додаток для скальпінгу на BingX Perpetual Futures з рішеннями від DeepSeek.
Нативний Kotlin + Jetpack Compose, торгівля триває у фоновому Foreground Service — без сервера,
Termux чи MT5.

Проєкт у розробці по фазах. Повний опис (отримання ключів BingX/DeepSeek, збірка APK, дозволи)
з'явиться в цьому README після завершення реалізації.
