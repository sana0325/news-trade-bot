# VEKTOR

Сигнальний бот по валютних парах, українською. Не термінал і не ставки: лише сильний сигнал
(пара, ВГОРУ / ВНИЗ, чому) і таймер 5 хвилин. Потім — результат словами.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # індикатори, сигнал, сесія, фід, рушій
npm run build    # статичні файли в dist/
```

## Як влаштовано

- `src/lib/indicators.js` — 25 індикаторів (12 середніх, 13 осциляторів), голос buy / sell / neutral.
- `src/lib/signal.js` — правила сигналу, впевненість, результат через 300 с.
- `src/lib/session.js` — сесія форексу за America/New_York, час Києва.
- `src/lib/market.js` — симуляція: тік 280 мс, свічка 15 с, 128 свічок історії, до 140 у пам’яті.
- `src/lib/binarium.js` — OTC-фід публічного графіка Binarium кожні 2.5 с.
- `src/lib/patterns.js` — дві стратегії на закритих свічках:
  - **Відбиття від рівня**: рівень з ≥ 2 дотиків (локальні мінімуми / максимуми в межах 0.3 ATR),
    остання свічка торкнулась його, лишила тінь ≥ 30% діапазону і закрилась від рівня.
  - **Пробій клина**: за ~36 свічок лінії максимумів і мінімумів сходяться (ширина впала > 35%),
    остання свічка закрилась за межею, попередня — ще всередині. Спадний клин угору і висхідний униз
    вважаються класикою і мають вищу впевненість.
- `src/lib/engine.js` — усе разом: ≤ 3 активні сигнали на всі стратегії, пауза пари 4 хв.
  Патерн перевіряється першим, бо живе одну свічку. Перемикач стратегій у шапці екрана.

**Будні:** пари зі справжніми цінами Twelve Data через WebSocket (`src/lib/twelvedata.js`),
за замовчуванням лише EUR/USD. Безкоштовний тариф дає WebSocket лише для пробного списку
символів (до 8), тому в застосунку є кнопка «Перевірити»: бот підписується на 21 пару пачками
по 8, Twelve Data відповідає, які дає, і з доступних можна обрати до 8.

API-ключі вводяться в застосунку (кожен з нового рядка) і зберігаються лише на пристрої —
у репозиторії їх немає. Працює перший ключ; наступний береться, лише якщо Twelve Data відхилив
поточний повністю (якщо дав хоч одну пару — лишаємось на ньому).

Симуляції для спот-пар немає: до перших цін пара «офлайн», далі розігрів (52 свічки по 15 с,
~13 хв), лише потім голоси й сигнали. Свічки зберігаються на пристрої, тож після перезапуску
з перервою до 2 хв розігрів продовжується. Якщо ціни не йдуть 30 с, нових сигналів немає.

**Вихідні (OTC):** EUR/USD OTC і GBP/USD OTC. Браузер ходить на `/binarium/...`; у `npm run dev` і
`npm run preview` це проксі на `https://binarium.com`. Для іншого хоста задайте `VITE_BINARIUM_BASE`.
Якщо фіду немає, OTC-пари працюють на симуляції.

На пристрої зберігаються лише: звук, фільтр сили, чи закрита перша підказка, ключі Twelve Data,
обрані пари і свічки спот-пар.

## APK

GitHub Actions (`.github/workflows/build-apk.yml`) на кожен пуш у `main` збирає debug-APK:
тести → `npm run build` → `npx cap sync android` → `./gradlew assembleDebug`.
Готовий файл — в артефакті `vektor-debug-apk` на сторінці запуску в Actions.

Локально (потрібні JDK 21 і Android SDK):

```bash
npm run build && npx cap sync android
cd android && ./gradlew assembleDebug
```

В APK OTC-фід Binarium іде напряму через CapacitorHttp, без проксі.

**Фон і сповіщення (лише APK, `src/lib/native.js`).** Після запуску бот просить дозвіл на
сповіщення і вмикає фонову службу Android (`specialUse`) з постійним сповіщенням «VEKTOR працює
у фоні», щоб система не заморожувала процес: ціни, свічки й таймери йдуть і з вимкненим екраном.
Коли застосунок згорнутий, новий сигнал і його результат через 5 хвилин приходять сповіщенням.
На деяких телефонах (Xiaomi, Huawei, Samsung тощо) для VEKTOR ще треба вимкнути оптимізацію
батареї, інакше система може закрити його попри фонову службу.
