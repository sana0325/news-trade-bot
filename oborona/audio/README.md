# audio/

Усі звуки гри генеруються процедурно в `scripts/fx/Sfx.gd` (шум + синусоїди, без сторонніх файлів):
постріл, постріл ворога, вибух, далека артилерія, перезарядка, маркер влучання, фоновий гул, дзижчання дрона.

Щоб замінити звук власним CC0-файлом: покладіть `.ogg`/`.wav` сюди і в `Sfx._ready()`
замініть відповідний запис, напр. `streams["shot"] = load("res://audio/shot.ogg")`.
