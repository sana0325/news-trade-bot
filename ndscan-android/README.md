# ndscan для Android

Запускає ончейн-сканер `ndscan.py` і автоторгівлю `okx_trader.py` на телефоні 24/7, також при заблокованому екрані й у сплячому режимі (Doze).
Python працює всередині застосунку через Chaquopy. Торгова логіка скриптів не змінена.

## Встановлення

1. На телефоні відкрийте посилання і встановіть APK:
   - APK: https://github.com/sana0325/news-trade-bot/releases/download/ndscan-latest/ndscan.apk
   - архівом: https://github.com/sana0325/news-trade-bot/releases/download/ndscan-latest/ndscan.zip
   Android може попросити дозволити встановлення з невідомих джерел.
2. При першому запуску дозвольте сповіщення і **виняток з оптимізації батареї**.
3. Вкладка **«Телефон»**: увімкніть автозапуск, батарею «Без обмежень», закріпіть ndscan у недавніх.
4. Вкладка **«Налаштування»**: введіть Telegram токен і chat id та, за потреби, ключі OKX. Натисніть «Зберегти».
5. На **«Головній»** натисніть **СТАРТ**.

Оновлення ставиться поверх старої версії: ключ підпису і `applicationId` (`com.ndscan.bot`) сталі, тому дані зберігаються.
Збірка: GitHub Actions (`.github/workflows/build-ndscan-apk.yml`) на кожен push у `ndscan-android/`. APK є в артефакті й у релізі `ndscan-latest`.

## Як влаштовано

- `BotService`: foreground-сервіс типу `specialUse` з постійним сповіщенням (статус, блок, сигнали за 6 год, час останнього циклу).
  Поки бот працює, тримає `PARTIAL_WAKE_LOCK` і `WifiLock` (`WIFI_MODE_FULL_HIGH_PERF`). Повертає `START_STICKY`, а після змаху з недавніх піднімається знову.
- `BootReceiver`: автостарт після перезавантаження й після оновлення застосунку, якщо бот був увімкнений.
- `WatchdogWorker` (WorkManager, кожні 15 хв): якщо сервіс мертвий або Python понад 5 хв не оновлював heartbeat, перезапускає.
- `python/runner.py`: запускає `ndscan.scan()`. Якщо він впав: traceback пишеться в лог, у Telegram іде «бот впав, перезапускаю», через 30 с запуск повторюється. Раз на 6 год шле в Telegram heartbeat.
- Файли стану (`state.json`, `signals.csv`, `watchlist.json`, `learned_deposits.json`, `universe.json`, `trades.json`, `trades.csv`, `log.txt`) лежать у пам'яті застосунку (`filesDir`).
  При першому запуску туди копіюються `universe.json`, `open_signals.json` і `signals.csv` з ПК. `cex_wallets.json` оновлюється з кожною версією.
- Ключі зберігаються в `EncryptedSharedPreferences`. У `tg.json` і `okx_keys.json` вони записуються лише перед стартом бота.

### Правки в Python (лише для Android)

- `ndscan.py`:
  - `DIR` береться зі змінної `NDSCAN_DIR`, а без неї — як раніше;
  - додано прапорець `STOP` і функцію `request_stop()` (кнопка «Стоп»): цикл виходить і викликає `save_state`;
  - `log()` дублює рядки в UI і в ротований `log.txt` (2 МБ × 3 файли);
  - додано `STATUS` для сповіщення.
- `okx_trader.py` без змін.

## Чекліст ручного тесту

- [ ] СТАРТ → заблокувати екран на 1 годину → у лозі («Поділитися логом») між рядками «працює: блок …» немає розривів довших за 2 хв.
- [ ] Змахнути застосунок з недавніх → сповіщення лишається, лог іде далі.
- [ ] Перезавантажити телефон → бот стартує сам (сповіщення з'являється після розблокування).
- [ ] Вимкнути інтернет на 5 хв → у лозі «помилка циклу» → увімкнути → бот продовжує сам, без натискань.
- [ ] Натиснути СТОП → у лозі «Зупинено», сповіщення зникає, після перезавантаження бот не стартує.
- [ ] Увімкнути РЕАЛ в OKX → з'являється діалог підтвердження.
